How it works
  • Report

    File a lost or found report with description, category, location and a photo.

  • AI Matches

    Text, image, location, category and date signals are combined into a match score.

  • Claim

    The likely owner answers private verification questions only they should know.

  • Human Review

    An admin checks the evidence and approves — AI never decides ownership alone.

  • Safe Handover

    Item is returned via a safe public handover or an authorized desk/authority.
